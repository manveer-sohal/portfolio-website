Clash Royale Hub

A hub for exploring Clash Royale player stats, battle histories, balance changes, and clan insights with a clean, responsive interface. Includes views for player profiles, recent battles, clan rosters, war logs, and a searchable card browser. The project uses the Clash Royale API to fetch data and the Clash Royale API is used to fetch data and the Clash Royale API is used to fetch data.

Tech Stack

TypeScript React Tailwind CSS Clash Royale API
Live Demo Github

Features

Player Profile

View player profile with stats, trophies, and recent battles.

Compare with friends and track progress over time.




Battle Log

Inspect recent matches with outcomes, trophies, and opponent details.




Clan View

See clan roster with member roles, trophies, and activity.

Navigate to any member profiles and compare stats.




Clan War Log

Track recent war performance, standings, and contributions.

Highlight streaks and identify top performers.

Navigate to partipcating clans and see their stats.




Cards Browser

Browse all cards with rarity, elixir cost, and quick search.

Great for building decks and studying the meta.
