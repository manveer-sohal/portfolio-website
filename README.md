# Manveer Sohal — Portfolio

Next.js + TypeScript portfolio for Manveer Sohal, positioned as a full-stack developer building AI-assisted products.

## Stack

- Next.js App Router
- TypeScript
- Tailwind CSS
- Static generation for pages and case studies

## Quick start

```bash
npm install
npm run dev
```

## Key paths

- `app/` — routes and metadata
- `components/` — UI and section components
- `data/` — editable project, experience, skills, and site content
- `public/` — images and documents
- `legacy/` — previous static HTML site (reference only)
- `docs/portfolio-redesign/` — migration, design system, content review, deployment

## Scripts

| Command | Purpose |
|---|---|
| `npm run dev` | Local development |
| `npm run build` | Production build |
| `npm start` | Serve production build |
| `npm run lint` | ESLint |
| `npm run optimize-images` | Optional WebP generation (requires `sharp`) |
